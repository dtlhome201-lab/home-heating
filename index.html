이 기기에서 저장 권한 설정

기기마다 한 번만 넣으면 됩니다. 토큰은 이 기기 브라우저에만 보관되고 GitHub 외 다른 곳으로 보내지 않습니다. 만드는 방법은 저장소 README에 있습니다.

  1. 집 특성 학습: 운전 설정을 바꾼 날 이전의 검침값을 7일 이상 단위로 자동으로 묶어, 하루 사용량 = α + β × 난방도일(외기온도가 τ보다 낮은 만큼) 관계를 찾습니다. PRISM(Princeton Scorekeeping Method) 방식이며 근거는 Fels, “PRISM: An Introduction”, Energy and Buildings 9(1–2), 1986.
  2. 자동 보정: 설정을 바꾼 날 이후의 기록은 학습에 쓰지 않고, 예측과 실제의 차이를 재서 남은 기간 예측에 반영합니다. 기록이 적을 때는 조금만, 쌓일수록 크게 반영됩니다.
  3. 실내온도: 실내를 1°C 올리면 난방이 필요한 외기온도 기준(τ)도 1°C 올라간다고 봅니다.
  4. 난방수 온도: 콘덴싱 보일러는 환수 온도가 낮을수록 배기 수증기가 응축돼 효율이 오릅니다. 난방수 50°C와 70°C 효율 사이를 직선으로 잇습니다.
  5. 외기온도: 기상청 날씨누리 과거관측(ASOS 일평균기온). GitHub Actions가 매일 새벽 자동으로 받아옵니다. 구는 가장 가까운 관측소에 연결하고, 아직 오지 않은 날은 작년 같은 날 기온으로 계산합니다.
  6. 요금: 지역 도시가스 주택용 단가(원/MJ) × 43 MJ/m³ × 부가세 10% + 월 기본요금. 작년과 올해 모두 현재 단가로 계산해서 사용량 차이만 비교합니다.
  7. 작년 10월 1일~11월 7일은 검침 기록이 없어 모델로 채웠습니다(그래프의 연한 막대).
